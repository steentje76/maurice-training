  GitHub → jouw branch → Add file → Create new file
  → typ als bestandsnaam:  .gitignore
  → plak de inhoud van gitignore-INHOUD-VOOR-GITHUB.txt (staat hiernaast)
  → Commit

Dat pad werkt wél met dotfiles.
