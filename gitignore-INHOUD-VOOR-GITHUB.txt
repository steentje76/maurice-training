# Trainingskompas — .gitignore
#
# Twee doelen: (1) sleutelmateriaal en secrets kunnen NOOIT per ongeluk in Git
# belanden, en (2) gegenereerde build-uitvoer vervuilt de geschiedenis niet.
#
# Elk patroon hieronder is vóór opname vergeleken met `git ls-files`: geen enkel
# bestaand, getrackt bronbestand valt eronder. Voeg hier dus niets toe zonder die
# controle — een te breed patroon sluit stilzwijgend projectbestanden uit.
#
# LET OP: .gitignore is een dotfile. Bij overdracht via een ZIP of een upload in de
# GitHub-webinterface kan hij ongemerkt wegvallen; dan bestaat deze bescherming
# niet meer. core/fAndroidRelease.test.js sectie D bewaakt daarom in CI dat dit
# bestand aanwezig is én dat er geen sleutelmateriaal in de Git-index staat.
# ─────────────────────────────────────────────────────────────────────────────
